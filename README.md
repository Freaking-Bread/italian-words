# 🇮🇹 Il mio italiano — Мой итальянский

Персональный сайт для изучения итальянского: слова с переводом и **примером в контексте**,
связки, правила (с картинками), отметка «выучил», поиск, а также вкладка **«Песни»** —
текст по-итальянски слева, перевод справа и встроенный плеер. Тёмная тема, работает на телефоне и ПК.

## Архитектура: публичный код + приватные данные

Статический сайт (без сборки) хостится бесплатно на **GitHub Pages** из этого публичного
репозитория. Реальные слова, песни и mp3 хранятся **не здесь**, а в отдельном приватном
репозитории `italian-words-data`.

```
italian-words/            ← публичный репозиторий (код + демо-данные)
├── index.html            # разметка
├── css/styles.css        # оформление, тёмная/светлая тема, адаптив
├── js/
│   ├── config.js         # настройки: указывает на приватный репо данных
│   ├── store.js          # данные: состояние + localStorage + CRUD   ← «бэк»
│   ├── github.js         # синхронизация + загрузка mp3/картинок      ← «бэк»
│   └── app.js            # интерфейс: рендер слов и песен, тема        ← «фронт»
├── data/
│   ├── words.json        # ДЕМО-слова (публичные)
│   └── songs.json        # ДЕМО-песня
└── .nojekyll

italian-words-data/       ← приватный репозиторий (реальные данные)
├── words.json            # твои слова / связки / правила
├── songs.json            # твои песни (текст + перевод)
├── audio/                # mp3-файлы песен
├── images/               # картинки к правилам
├── WORDS.txt             # исходный список слов
├── import.mjs            # WORDS.txt → words.json
└── REVIEW.md             # разбор ошибок перевода
```

## Как это работает

1. Открываешь сайт (URL GitHub Pages) — видишь демо-данные.
2. Жмёшь ☁️ → вставляешь GitHub Personal Access Token (доступ к приватному
   `italian-words-data`, Contents: read/write) → «Загрузить из GitHub».
3. Приложение подтягивает твои слова и песни. Правки коммитятся обратно в приватный репо.
   mp3 и картинки тоже тянутся из приватного репо по токену. Токен хранится только в браузере.
4. На телефоне — то же самое: открыл URL, один раз вставил токен.

## Вкладки

- **📖 Слова / 🔗 Связки / 📐 Правила** — карточки с переводом и примером в контексте;
  кнопки 🔊 (озвучка it-IT), 📚 «Примеры» (Reverso Context), 🗣 YouGlish (произношение).
  Правила могут содержать картинку.
- **🎵 Песни** — список песен → открываешь песню → сверху плеер, ниже две колонки:
  итальянский текст ↔ перевод (на телефоне строки чередуются).
